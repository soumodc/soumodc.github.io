VMS Tracker - Privacy policy

What the app accesses

With your permission, VMS Tracker uses the Gmail API with the read-only scope (gmail.readonly) for the one mailbox you sign in with. It searches only for VMS report emails from info@vms.fknakshatra.com and reads the report download link in them. It does not read, store or process any other email, and it never sends, changes or deletes email.

What it does with the data

It downloads the VMS scan report the email links to, compares its AWB numbers with the team's own shipping data, and writes the result to the team's own Google Sheet. A copy of each report is kept on the PC that runs the tracker for up to 30 days, then deleted. The Gmail sign-in token is stored only on that PC.

Sharing

No data is sold, shared with third parties, used for advertising, or sent anywhere except the team's own Google Sheet.

Google API Services User Data Policy

VMS Tracker's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

You can remove the app's access at any time at myaccount.google.com/permissions. Deleting the tracker folder from the PC removes the stored token and report copies.

Contact

Use the support email shown on the Google sign-in screen of VMS Tracker.
